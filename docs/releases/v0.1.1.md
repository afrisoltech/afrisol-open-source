# v0.1.1 — reviewed shared-component contributions

This release adds the shared-component catalogue, contribution and disclosure checklists, ownership rules, dependency updates, and public-boundary assurance from PR #4.

The localization API and its MIT-licensed source are unchanged from v0.1.0. Accessibility and low-bandwidth entries remain proposals. The APOS consumer verifies immutable release identity, file hashes, license and exact-source public checks before proposing private adoption. Private improvements produce review bundles; they are not published automatically.

Public main temporarily requires no approving review during the explicitly authorized sole-maintainer period. Pull requests, Python 3.10/3.12 checks, public-boundary checks, up-to-date branches and resolved conversations remain required. Restore one independent approving review when another maintainer is onboarded.

Validation: release only after the exact release commit passes required tests and boundary assurance. APOS adoption is recorded separately in its private activation tracker; this release does not represent a production deployment.
