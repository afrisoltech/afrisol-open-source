# Sponsorship and Community Impact

Afrisol Technologies welcomes individuals, developer communities, foundations and businesses supporting African open source innovation.

[Become a sponsor](https://github.com/sponsors/afrisoltech)

## Intended uses
Sponsorship can support independent open source engineering, testing, security reviews, documentation, learning materials, accessibility and developer collaboration. These are intended priorities, not claims that any particular funded activity has already occurred.

## Recognition and boundaries
Recognition is optional and subject to the sponsor's consent and GitHub Sponsors' available features. Sponsorship does not buy confidential information, guaranteed feature acceptance, preferential security treatment, access to private repositories or APOS production systems, software licences, consulting, or procurement outcomes. Commercial services are governed separately.

## Transparency
Publish meaningful project milestones and updates where practical. Do not disclose donor personal data or assert audited financial allocations without evidence.
