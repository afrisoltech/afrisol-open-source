# Africa-Focused Community Programmes

## Contribution pathways
- **Students and new developers:** documentation, localization tests, accessible tutorials and beginner-friendly issues
- **Software developers:** small libraries, code reviews, test coverage and API examples
- **Researchers:** reproducible experiments using public or synthetic data and clear ethics documentation
- **Startups and institutions:** public interoperability proposals and reusable, vendor-neutral tools
- **Sponsors:** financial support and feedback through public channels without privileged roadmap control

## Prioritization
Prioritize demonstrable African market needs such as low bandwidth, accessibility, multilingual interfaces, affordability, privacy and digital trust. Avoid treating Africa as a single market: requirements vary by country, regulation, language and infrastructure.

## Collaboration boundaries
This is not a registration portal for Ubunifu Institute, Goblis Foundation, investors or private Afrisol customers. Cross-organization partnerships require separately verified agreements and permissions.
