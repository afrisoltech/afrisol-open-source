# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues or discussions. Use GitHub's **Report a vulnerability** / private vulnerability reporting feature when enabled for this repository. If that feature is unavailable, contact Afrisol Technologies privately through https://www.afrisoltech.com and request a secure disclosure channel. Do not include credentials or sensitive exploit details in an unencrypted message.

## Scope

This policy covers code published in this repository only. It does not authorize testing of Afrisol's commercial APOS systems, customer environments, supplier integrations, or production infrastructure.

## Handling

Maintainers will triage reports, coordinate remediation and disclosure, and publish advisories when appropriate. No fixed response-time guarantee is implied.
