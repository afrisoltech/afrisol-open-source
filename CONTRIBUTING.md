# Contributing to Afrisol Open Source

Thank you for supporting Africa-focused technology innovation.

## Before contributing

1. Check existing issues and pull requests; discuss substantial changes before implementation.
2. Fork the repository or create a feature branch, make one focused change, and include tests and documentation when relevant.
3. Open a pull request describing the problem, approach, tests, and any security, licensing, accessibility, localization, or low-bandwidth implications.
4. Do not commit secrets, customer information, proprietary APOS code, supplier credentials, or third-party content without redistribution rights.
5. Treat all contributors respectfully and follow the code of conduct once published.

## Review

Maintainers review correctness, security, accessibility, licensing, relevance to African markets, and maintainability. Submission does not guarantee acceptance. Unless explicitly agreed otherwise, contributors retain ownership of their contributions and submit them under the repository's applicable licence.

## Sponsorship

Support independent open source work at https://github.com/sponsors/afrisoltech. Sponsorship does not confer privileged access to private customer systems or guarantee roadmap priority.
