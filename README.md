# Afrisol Technologies — Open Source

**Africa-focused technology innovation.** Building Technology for Africa, Creating Opportunities for the World.

Afrisol Technologies develops and supports technology initiatives intended to help African developers, startups, students, researchers, businesses and institutions participate in the digital economy. This public repository is a home for **independently developed open source** resources and community collaboration.

## Focus areas

- Responsible artificial intelligence and machine learning
- Cloud computing, DevOps and digital infrastructure
- Software engineering, open APIs and interoperability
- Cybersecurity, privacy and digital trust
- African digital commerce and financial technology education
- Accessible, mobile-first and low-bandwidth experiences
- Developer education, research and sustainable innovation

## Getting started

This repository is an early-stage community foundation. See [ROADMAP.md](ROADMAP.md) for planned work. There are **no published production-ready software packages here yet**. Open an issue to propose a small reusable tool, tutorial or example. Follow [CONTRIBUTING.md](CONTRIBUTING.md) before submitting a pull request.

## Separation from commercial systems

This public repository is independent of Afrisol's private **Afrisol-APOS** commercial platform. Do not submit private source code, credentials, supplier integrations, production infrastructure, customer information, or third-party proprietary material. Only independently developed or appropriately licensed content belongs here.
